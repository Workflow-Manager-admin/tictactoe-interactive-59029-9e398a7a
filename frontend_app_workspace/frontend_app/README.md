# Tic Tac Toe Flutter App

A modern, minimalistic Tic Tac Toe game with:
- Interactive board
- Single player (vs computer) and two player modes
- Win/draw detection
- Scoreboard
- New game/reset controls
- Responsive and centered mobile layout

## Getting Started

1. Install [Flutter](https://flutter.dev/docs/get-started/install).
2. In this directory, run:
    ```
    flutter pub get
    flutter run
    ```

## App Features

- Primary color: #1976D2
- Secondary color: #FFC107
- Accent color: #FF5252
- Board and controls centered for mobile
- Light theme, simple and accessible

## File Locations

- Main Dart code: `lib/main.dart`
